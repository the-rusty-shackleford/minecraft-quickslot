# D-0009: Quick Slot contributes its synced stack to Luminance

2026-09-18. Implements the original lighting brief and Rusty's authorization to finish
the remaining release gates. Release remains HELD.

Use the pack's Luminance 1.1+ interpolated entity-provider API and its existing
`Providers.luminanceOf` lookup, as the companion backpack mount integration does.
No new lighting engine, world-light blocks, other-mod mixin or bundled dependency.
The guarded adapter loads only on physical clients with Luminance present.

The player's synced attachment supplies both local and remote light. Cache dry/wet
levels per player, immutable stack snapshot identity and revision; clear on resource
reload and logout. Initial login can deliver a populated stack at the same revision
zero as the empty default, so revision alone cannot invalidate the cache.

Rendering eligibility is independent: hidden blocks, bowl meals and elytra-hidden
items can still illuminate if Luminance says they do. Honor Quick Slot's existing
dynamic-light toggle plus Luminance's settings, JSON definitions and underwater rules.
Use the same interpolated point as held light. Skip a redundant source when the held
item is equally bright or brighter; Luminance's field takes the maximum across held,
Quick Slot and backpack mount sources.

The initial real-client check reproduced zero light from a Quick Slot torch versus
14 when held. A later relog check exposed the revision-zero empty-cache bug; retaining
stack identity fixed it. See `knowledge/validation/lighting.md` for final evidence.

This closes the lighting implementation formerly pending in D-0008. It does not close
legacy retirement, backpack-aware presentation, controller/full-pack compatibility or
the other remaining release gates.
