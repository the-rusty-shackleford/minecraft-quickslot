# D-0005: Natural alternate carry or hidden body display

Accepted by Rusty on 2026-09-17. Supersedes the requirement in D-0001 to always keep
back items visible with elytra and the unconditional side hang for wide backpack items.

When elytra or other equipment covers the back, try an alternate position only if it
fits naturally. If no good fit exists, hide the body display (the "pocket verse").
The item remains stored, swappable and usable; rendering does not control lighting.

The initial elytra policy keeps narrow tools at the rear hip and hides shields, bows
and crossbows. Per-item placement resources can explicitly choose a tuned hip or
lower-back anchor. Every retained alternate position still requires real visual review.
Poses that obstruct the upper back use the same fallback if clearing the head/helmet
would require more than one pixel of rearward movement. This prevents visible floating;
the display returns when the pose has room again.
Capes hide back displays and redirect lower-back belt displays to the hip. This avoids
depending on a fixed offset for a moving cape. A cape's render toggle is respected.
The backpack phase must apply the same quality rule rather than forcing a wide item
outside the pack. This decision does not authorize a release or an external-mod mixin.
