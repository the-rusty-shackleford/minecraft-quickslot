# D-0004 — Inventory cell above offhand, mirrored HUD

Accepted 2026-09-17 after Rusty reviewed the interactive Phase 2 preview and approved
the layout and small InventoryMenu injection approach.

Append a real slot at item coordinates (77, 42), immediately above offhand (77, 62).
Keep existing menu indices intact. Constructor and shift-transfer `@Inject` hooks add
the cell and its transfer branches; ordinary clicks use the vanilla server menu protocol.
Shift-click from Quick Slot returns to ordinary inventory. From inventory, empty armor
or offhand auto-equipping takes priority; other items may enter an empty Quick Slot.

The HUD is opposite offhand, mirrors the main arm and reserves attack-indicator room
whenever the indicator is configured beside the hotbar. It shows item count, durability
and a brief authoritative-swap highlight. Swap mode does not introduce a selected tenth
hand slot. Render through RegisterGuiLayersEvent; inventory background uses screen events.

The menu uses a separate mutable working stack. Server attachment writes remain defensive
and synchronized; client menu prediction cannot become authoritative attachment state.
